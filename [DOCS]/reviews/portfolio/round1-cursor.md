## Findings

| Severity | Location | Problem | Fix |

| high | `portfolio.css:21-26`, `65-87`, `137-138` | Always-on GPU load: 160vmax `blur(120px)` spinning aurora, grid scroll, 3 orbit rings, 6 shards, float, sheen, morph blob. On phones this fights “smooth” motion and burns battery. | Gate infinite effects behind `@media (prefers-reduced-motion: no-preference)` and a `@media (max-width: 820px)` still sky (static gradient, no blur spin / shards). |
| high | `index.html:147-149` + `portfolio.css:7-12` | Page is forced dark (`color-scheme: dark`, dark paper) but shots use `prefers-color-scheme: dark` sources with **light** `<img>` fallbacks. | high | `index.html:32-38` + `portfolio.css:32,54-59` | Full-viewport intro (~2.3s) sits over real UI. `pointer-events: none` lets clicks through, but keyboard focus can land on header/hero controls while they are covered. | Keep intro decorative and non-covering, or delay interactivity with CSS (`pointer-events` on `.site-header`/`.me` until intro ends) and ensure reduced-motion already skips it (it does). |
| high | `portfolio.css:147`, `151`, `161`, `175` | Scroll timelines animate `filter: blur(...)` on large type and sections — expensive on scroll, especially mobile. | Animate only `opacity` / `transform`; drop blur from scroll keyframes. |
| medium | `portfolio.css:9` | Hard constraint is one accent `#d97757`; `--link` / `--focus` are `#eda083`. | Set `--link` and `--focus` to `#d97757` (tints only via alpha / `#d97757` mixes). |
| medium | `portfolio.css:210-214` | Reduced-motion zeroes animations and restores opacity on scroll classes, but not hero entrance targets (`.word`, `.kicker`, `.lede`, `.actions`, `.me-stage`) that use `animation-fill-mode: both` from opacity 0. | medium | `index.html:119-121` | Flagship video has controls and an accessible name, but no captions/descriptions for speech/SFX. | Add a `<track kind="captions">` (or a short transcript link under the video). |
